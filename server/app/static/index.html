                      BYO-API — your model, your credentials, your browser only

                      Your base URL, model, and credential are stored only in this browser's localStorage and sent directly from this browser to the model API. The local server never receives them — there is no server endpoint that accepts them, and a server request carrying one is rejected.

                      Access token — for opening this server from your phone

                      This server binds loopback only by default. A LAN bind requires a token configured on the server (a file outside this repo, never shown here). Paste that token once — it is stored only in this browser's localStorage and sent as the X-Grokbot-Token header on every local /api/* request. It is never sent in a request body and never to the model API.

                      No access token saved — loopback use needs none; a token-bound server answers 401 until you save its token.
